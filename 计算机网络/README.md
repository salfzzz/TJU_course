# 计算机网络

---

## 📚 课程简介
本课程是考研408统考核心科目之一，理论体系层级性强、概念抽象，同时实验占比高，需要同时兼顾理论理解与动手实践能力。

## 🧪 实验相关
本课程实验项目数量多、整体耗时较长，其中两类实验工作量最为突出：
1. **Socket编程实验**：实现复杂度高，需要手动编写客户端与服务端通信逻辑，代码调试和排错成本高，建议提前预留充足时间分步完成。
2. **Wireshark抓包实验**：需要实际抓取真实网络数据包，逐层拆解分析各协议字段与报文交互流程，细节繁琐，数据整理和分析工作量大。

## 💡 学习方法
1. 课程采用英文PPT授课，理论内容偏抽象，仅靠课堂吸收难度较大。
2. 课下推荐搭配**王道考研计算机网络**或**湖科大计算机网络**网课进行补充学习，更容易搭建完整的知识框架。
3. 可以入手王道《计算机网络》考研配套习题集，同步巩固课上知识点。
4. **考点提示**：本门课程期末考试**不考察物理层内容**，备考时可跳过该章节，聚焦核心层级的学习。

## 📝 复习建议
1. 可以将课程课件、历年期末真题整理后，借助AI工具梳理生成系统化的复习讲义与配套模拟题，针对性覆盖考点，复习效率较高。
2. 本文件夹内已附上整理好的复习讲义、模拟题等资料，可以直接参考使用。

## 📌 考试特点与备考建议
1. **考试风格**：2026年期末考试内容偏抽象，整体难度与区分度较高。
2. **核心大题**：有一道40分以上的综合大题，同时覆盖**数据链路层、网络层、传输层**三层内容，考察多层协议。
3. **细节考点**：试卷包含不少细致化的考点，对知识点掌握的深度和熟练度要求更高，不能只记忆框架。
4. **刷题建议**：同样可以参考**408考研计算机网络真题**进行刷题练习，考点重合度高，训练效果好。
