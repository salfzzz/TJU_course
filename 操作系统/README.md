## 📚 课程简介
本课程是考研408统考的核心科目之一，部分知识点与计算机组成原理高度重合，学习时可以相互关联理解。

## 🧪 实验相关
### 实验安排
本课程共设置6个实验项目，基于xv6操作系统动手实现各类核心功能。
实验仓库地址：(https://gitee.com/tjucs/xv6-homework) 都不难，借助ai

## 📝 考试相关
### 复习重点
1. **优先刷408历年真题**
   近两届期末考试中，**90%以上的题目均直接取自考研408操作系统原题**，真题是期末复习性价比最高的资料，这里就不再给出我用ai复习的资料
   在线刷题地址：https://www.csgraduates.com/study_methods/408quiz/2026/
   刷完题库中操作系统板块的全部题目后，期末考试基本等同于“默写答案”，可以一小时内快速完成答卷。

2. **重视日常课堂学习**
   课上内容一定要认真听讲、及时消化，不要把所有复习压力留到期末。如果本课程和计算机网络同时堆到期末突击，复习强度会比较大，时间安排会十分仓促。
