# 信息系统安全：PPT 考点总目录

本目录依据文件夹内 18 份 PPTX 整理，共 1,435 页。第 2 讲的三个版本、第 5 至第 7 讲的分册以及第 9 讲的专题课件均纳入。少数封面的讲次与文件名不一致，本目录按文件名和实际主题归类。页码指对应 PPT 的幻灯片序号。这里列出**课件范围内可能命题的知识点**，并不代表教师已公布的考试范围或出题概率。后续逐章讲义应覆盖概念、原理、比较、流程、计算、应用判断和所有练习题。

## 第 1 讲：信息系统安全概述

- 信息安全、信息系统安全、系统安全、网络安全、网络空间安全的研究对象和区别；机密性、完整性、可用性，以及真实性、可控性。
- 信息系统的资产、威胁、脆弱性、风险之间的关系；自然与人为威胁、内外部威胁；硬件、软件、数据、网络、协议和移动介质的脆弱性；攻防不对称性、复杂性、信息属性造成的脆弱性。
- 风险评估、安全需求、安全措施的衔接；定量风险分析与“威胁 × 脆弱性 × 资产价值”表达；边界防护和等级保护。
- 安全观念从通信保密、计算机安全、信息安全发展到信息保障；CMM、IATF、5432 框架；主动防御、动态防御、技术与管理结合；技术、管理、标准、法律体系和管理原则。
- 课件中的关键信息基础设施、工控攻击、震网、数据库和移动介质案例，用于辨认威胁、漏洞、资产及后果。
- 明确习题：第 91—95 页，重点辨析 CIA、恶意软件防御、风险、威胁和脆弱性。

## 第 2 讲：物理安全、可靠性与容错

- 物理安全的范围；机房环境的温度、湿度、洁净度；防火、防水、防盗、门禁与监控；机房相关标准。机房建设方案是课件中的情境题。
- 线路安全：电缆与光缆、海底光缆、搭线窃听、光纤中继环节的风险。
- 电源安全：供电方式、稳压/隔离、不间断电源 UPS、防静电、保护接地与其他地线、防雷。
- 电磁泄漏、辐射与传导途径、TEMPEST、屏蔽与干扰；侧信道攻击的声、光、时间、功耗和电磁信息；介质保护。
- 可靠性、故障、容错系统；故障检测与诊断、故障屏蔽、联机/脱机检测、自校验；硬件、软件、数据冗余及其差异；容错中的信息保护。
- 明确习题：2026 版第 125、126、131 页；另外两个版本内容相同但页码后移。重点是机房物理措施、物理与网络安全的交叉、侧信道信息泄漏。

## 第 3 讲：身份认证

- 身份认证与消息认证、授权的区别；“知道的、拥有的、固有的”认证因素；静态口令的弱点、嗅探和重放攻击。
- OTP、HOTP/TOTP、时间和事件同步、SecurID、双因素与多因素认证；TOTP 共享密钥、时间窗口与口令生成条件。
- 生物特征的类别、比较及攻击风险。
- 对称/非对称加密、哈希、数字签名、机密性与完整性的组合；中间人攻击及证书的作用。
- PKI 的 CA、RA、证书库、证书撤销和验证、信任链；X.509 证书结构及浏览器验证网站身份的过程。
- Kerberos 的 AS、TGS、服务端、TGT、服务票据、认证符、会话密钥；报文交换流程、时间戳、优势和局限；USB Key/Token。
- 明确练习：第 41—44 页 TOTP 四题；第 95—96 页密钥用途和浏览器证书验证；第 116、120 页 Kerberos 选择题。

## 第 4 讲：零知识证明

- 零知识证明的参与方、目的和安全要求；交互式与非交互式证明；“分隔与选择”迷宫协议。
- 每轮欺骗概率 1/2，连续 n 轮为 (1/2)^n 的计算与解释。
- GMR 与 FFS 模型、Feige–Fiat–Shamir 身份识别；证明身份而不泄露秘密的过程。
- 象棋大师问题和黑手党骗局所示的转发/中继攻击；解释为何单靠证明过程不能排除这种攻击。
- 课件第 9—20 页含协议示例、概率计算和攻击情境，无单独标为“习题”的页面。

## 第 5 讲：访问控制与完整性模型

- 主体、客体、操作、权限、安全策略；认证与访问控制的关系；网络、主机、应用层访问控制。
- DAC、MAC、RBAC 的授权依据及比较；访问控制矩阵、ACL、能力表；最小权限与职责分离。
- BLP 机密性模型、Biba 完整性模型的安全级别、读写规则和信息流判断；低水标、环模型、严格完整性模型。
- Chinese Wall 模型的利益冲突约束；Clark–Wilson 模型的 CDI、UDI、TP、IVP 与良构事务。
- RBAC0—RBAC3、角色继承、用户/权限指派、会话、静态和动态职责分离、互斥约束及基数限制。
- Merkle 树的哈希构造、验证路径和完整性验证。
- 明确练习：访问控制主册第 76—79 页 BLP/Biba 与信息流判断，第 91 页角色冲突情境，第 104 页 DAC/MAC 比较及 RBAC 特点，第 105 页模型分类题。完整性分册第 9—16、25—36 页适合规则判断和验证路径题。

## 第 6 讲：操作系统安全

- 操作系统威胁、安全需求与安全策略；可信计算基 TCB、TCSEC、安全功能和评估要点，包括标识鉴别、审计、客体重用与隐蔽信道。
- Windows 身份认证、域、SAM、LM Hash/NT Hash、NTLM、口令和锁定策略、离线破解与彩虹表风险。
- Windows SID、访问令牌、安全描述符、DACL/ACE；显式拒绝、组权限叠加、有效权限判定；审计策略与日志。
- Linux 账号信息、身份认证、rwx 权限和八进制表示、chmod、日志；Symbian/智能终端安全和应用签名。
- 明确练习：操作系统主册第 76、88—94 页 Linux/Windows/Android 选择题；Windows 专册第 23、33、41、60—61 页 LM Hash 和有效权限讨论题。

## 第 7 讲：数据库安全与 SQL 注入

- Oracle 的例程与数据库、连接和安全体系；用户、系统/对象权限、角色、概要文件、资源限制、备份恢复与闪回。
- SQL Server 身份认证模式、登录与数据库用户、授权与回收、备份和恢复、数据加密。
- GRANT、REVOKE、SELECT 等授权语句的语法和作用；最小权限、基于角色的授权。
- SQL 注入形成条件和登录绕过；参数传入、注释符、UNION、错误型、布尔/时间盲注、堆叠查询、存储过程、Cookie 注入；参数化查询/PreparedStatement、输入校验和权限限制。
- 明确练习：Oracle 册第 33—40 页安全措施和 GRANT/REVOKE 选择题；SQL Server 册第 70 页三道作业；SQL 注入册第 5—25、31—56 页的查询与注入推演。

## 第 8 讲：计算机取证

- 计算机取证、电子证据的定义、目标、流程和原则；司法鉴定、证据范围界定。
- 计算机、移动终端、相机、移动存储、网络设备及打印扫描设备中的潜在证据；用户文件、系统文件、隐藏/残留数据。
- 证据收集、镜像复制、保存、完整性校验及证据链；常见软硬件取证工具及其用途。
- 明确练习：第 51 页计算机取证目标选择题。

## 第 9 讲：恶意代码与缓冲区溢出

- 恶意代码、病毒、蠕虫、木马、后门/陷门、逻辑炸弹的定义、寄生性、自繁殖性、传播和运行方式比较。
- 病毒的特征、存在状态、分类、引导/感染/表现模块；引导区病毒、Win32 PE 病毒的关键机制；病毒检测、清除和防护。
- 蠕虫的网络扫描、传播、攻击与复制模块；木马的植入、隐藏、连接、远控与客户端/服务端结构；后门的账号、网络通信与系统级形式；其他恶意代码和恶意广告。
- 程序内存布局、栈与缓冲区、溢出原因和后果；覆盖返回地址的原理、攻击过程与防护思路。
- 明确练习：计算机病毒专册第 35—42 页八道选择题和第 44 页四道思考题。图片版“恶意程序攻击”覆盖病毒、蠕虫、木马、陷门和其他恶意代码，已逐页检查其图片内容，并与可提取文字的第九讲及病毒专册交叉核对。

## 编写逐章讲义时的核对规则

1. 每个概念给出定义、适用条件、与相近概念的区别及一个判断例子。
2. 每个模型/协议给出步骤或规则，并使用 PPT 中的练习题验证。
3. 单列所有明确的练习、作业、讨论和情境题；给出答案与理由。PPT 中若有过时或有争议的表述，标明“课件说法”和现行技术解释。
4. 题目和答案都标注原 PPT 页码，避免不同版本页码混用。
