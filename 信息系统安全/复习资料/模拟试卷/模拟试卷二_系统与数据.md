# 信息系统安全模拟试卷（二）｜访问控制与系统安全

**考试范围：第一至第九讲课上 PPT。建议用时：120 分钟；满分：100 分。** 填空 20 分、单项选择 20 分、简答 60 分。答案见独立文件《三套模拟试卷_答案与评分要点》。

## 一、填空题（10 题，每题 2 分，共 20 分）

1. 课件“5432”信息安全框架中的“5”指五项安全属性：机密性、完整性、可用性、真实性和________。

4. 零知识证明中，没有秘密的证明者难以使诚实验证者接受，这一性质称为________性。
5. 严格 Biba 模型为了保护完整性，禁止向下读、禁止向上写；允许的信息流总体从________完整性级别流向________完整性级别。
6. Windows 用于标识用户、组等安全主体的安全标识符简称________。
7. Oracle 用于限制会话数、CPU、空闲时间及管理口令参数的一组用户策略称为________。
8. Windows 对象安全描述符中，用于规定哪些访问需要记录到审计日志的是________。
9. 取证镜像生成后，可通过比较来源与镜像的________值来核验内容一致性。
10. C 语言 `char buf[8]` 若作为以 `\0` 结尾的字符串，最多可保存________个普通单字节字符。

## 三、简答题（6 题，每题 10 分，共 60 分）

21. **安全保障框架。** 写出“5432”框架中 5、4、3、2 分别代表什么；再解释为什么课件强调动态防御，而不能只依赖一次性配置。
22. **物理安全与容错。** 比较可靠性、容错和冗余；说明硬件、软件、时间、数据/信息四种冗余各举一例。为什么两份完全相同的软件代码不能消除共同设计错误？
23. **认证与零知识。** 说明“密码+安全令牌”为什么是双因素，而“密码+安全问题”通常不是；写出零知识证明的完备性、可靠性、零知识性，并计算迷宫协议连续 10 轮的理想欺骗成功概率。
24. **DAC/MAC/RBAC 与 Chinese Wall。** 比较访问控制矩阵、ACL、能力表；说明 RBAC0、RBAC1、RBAC2、RBAC3 的增加关系与 SSD/DSD 区别；用竞争公司的例子解释 Chinese Wall 如何依据访问历史限制权限。
25. **Windows/Linux 权限。** 用户 U 对 Windows 文件有允许读写，所属组 G 对该文件有显式拒绝写，按规范 ACE 顺序分别请求读、写时各是什么结果？一次请求“读+写”呢？另将 Linux 文件 `-rwxr-xr--` 写成八进制，并说明组成员有何权限。
26. **数据库与应急取证。** 某 SQL Server 数据库发生误删，同时一台应用主机出现异常外连。说明完整备份、差异备份、事务日志备份的恢复顺序；指出应用数据库账户如何贯彻最小权限；若要调查异常主机，应先保护什么易失性信息、怎样制作与验证镜像、在哪里分析？
