# 网络安全考试复习内容：16 题答案与知识补充

**依据范围**：题目来自《考试复习内容.jpg》。第 1—14、16 题及知识补充仅据所提供九份 PPT 整理；第 15 题按要求结合工作区中的《B-交付文档.docx》和《B任务汇报问答准备.docx》。文中“课件第 N 页”指 PPT 中从 1 开始计数的幻灯片序号。以下是对课件的归纳，非逐字照抄。

## 一、16 道题

### 1. 什么是基于流量的攻击？具体有几种类型？

基于流量的攻击针对网络中的数据流量。课件概括为**两类**：一是**嗅探、窃听**，截取流量以获得信息；二是**制造大量流量**，如广播包或大量请求占用带宽与设备处理能力，使正常流量下降甚至网络瘫痪。有线以太网和无线网络的章节均按这两类讨论。**依据**：chapter 4，第 15 页；chapter 5，第 27—28、50、59 页。

### 2. 基于 TCP 协议的攻击是什么？针对哪个漏洞？怎样实施？

这里的典型答案是 **SYN 雪崩式攻击（SYN flood）**。它针对 TCP **三次握手中服务器收到 SYN 后要为未完成连接分配资源**这一机制。攻击者不断发送 SYN 请求，却不完成最后的 ACK，形成大量半打开连接，耗尽服务器的 TCP 缓冲区或连接资源，导致正常用户无法建立新连接。课件还提到限制同一源 IP 的半打开连接数、在网络入口检测过滤等缓解思路；分布式攻击更难区分。**依据**：chapter 4，第 11 页；chapter 7 new，第 12—14 页。

### 3. WPA 用什么提供安全？如何工作？有什么漏洞？

WPA 同时使用**验证和加密**。家庭环境中，无线设备和接入点共享验证密码；密码用于验证，验证成功后双方协商该设备专属的会话加密密钥，再用会话密钥加密无线设备与接入点间的数据。企业环境中，接入点结合验证服务器确认用户身份，授权后再协商会话密钥。课件指出的风险是：攻击者捕获验证会话后可尝试**猜测共享密码**，成功后可接入网络；若观察到足够流量，也可能发现会话密钥，但其影响限于相应设备和有效期。WPA 也不能阻止无线信号被恶意阻塞或无线雪崩。**依据**：chapter 5，第 53—59 页。

### 4. 减少物理网络攻击有哪些常用对策？怎样起作用？

**交换式网络**使单个端口通常只连接一台设备，普通设备难以看到其他端口的单播流量；**VLAN**把广播和流量限制在各自的逻辑网络，缩小可嗅探范围；**加密**使攻击者即便截获数据也难以读出内容。无线网络使用 WPA 的验证与加密；接入控制可限制未经授权的设备连接。要注意，课件也说明交换机并不能根除 ARP 中毒等让流量绕经攻击者的手段，VLAN 和加密分别解决不同问题。**依据**：chapter 5，第 13—14、22—27、50、53—59、61—64 页。

### 5. ARP 欺骗可实现哪些攻击？如何防范？

ARP 收到请求或应答时，可能不验证其中 IP 与 MAC 的对应关系就更新缓存。攻击者利用伪造映射，可让受害主机**无法与其他主机通信**，或使流量经过攻击者，构成**中间人攻击**，进而监听或篡改数据。课件给出的防范措施是**静态 IP—MAC 绑定**和**ARP 防火墙**；后者限制随意刷新 ARP 缓存，只有本机发出 ARP 请求后才依据应答更新。**依据**：chapter 6，第 6—10 页；chapter 5，第 22—23 页。

### 6. 什么是 ARP 缓存中毒？结果是什么？

攻击者发现 ARP 请求后，抢在真实应答之前发送虚假的 ARP 应答，让错误的 IP—MAC 映射进入受害者的 ARP 缓存。若映射到无效硬件地址，受害者与目标设备通信受阻；若映射到攻击者的 MAC 地址，数据包便被送往攻击者主机，可能形成中间人位置。它是 ARP 欺骗的一种具体表现。**依据**：chapter 6，第 16 页；chapter 5，第 23 页。

### 7. 什么是 IP 地址欺骗？为什么容易实现？

IP 地址欺骗是在数据包中填写**并非发送设备自身 IP 的虚假源地址**，使接收方误认来源。它容易实现，是因为源 IP 由**发送者写入 IP 头部**，目的主机在基本 IP 传输中必须先相信这个字段；IP 地址本身不能证明发送者身份。课件指出路由器可检查与其直连网络不符的源地址，但这依赖路由器配置，也不能阻止同一局域网内冒用别的主机地址。**依据**：chapter 3，第 11 页；chapter 6，第 17、21—23 页。

### 8. 什么是网络层的泛洪攻击？如何防范？

课件的典型例子是利用**伪造源 IP 的 ICMP 回显请求和定向广播**：攻击者把源地址写成受害者地址，请求送到某网络的广播地址，若路由器转发，网络内多台主机都向受害者回送响应，放大流量并可能压垮受害者或相关网络。防范包括路由器**禁止转发定向广播**、按需要限制外部 ICMP 回显请求，以及对进入网络的包量做限制；限流过严也可能影响正常通信。**依据**：chapter 6，第 18、27—29 页；chapter 4，第 15 页。

### 9. 什么是欺骗性 DHCP 服务器？为什么能存在？

欺骗性 DHCP 服务器是攻击者在同一网络中伪装成合法服务器，对客户端的地址请求发送虚假应答。它可分配无效地址，使客户端一段租期内无法正常通信。其存在的根源是**客户端无法凭 DHCP 协议本身识别服务器身份**；同网段可以有多个服务器同时回应广播请求，客户端可能收到多个应答。**依据**：chapter 6，第 32、37—38 页。

### 10. 针对 IP 层安全漏洞，有哪些防范手段？

课件将常用 IP 层对策归为四项：**IP 过滤**（按 IP 地址、端口号、协议类型阻止流量）；**NAT**（使用地址映射，默认不转发无映射的入站包）；**VPN**（在双方设备或网络间建立加密、验证的通信信道）；**IPsec**（在 IP 层提供验证与加密，减少嗅探和冒用）。此外，针对具体攻击还可做源地址检查、禁止定向广播、限流以及对畸形分片进行检查。各措施有局限，例如 NAT 并非专为安全设计，IP 过滤不能代替防火墙。**依据**：chapter 6，第 5、18、21—22、29、41—49、53、60—65 页。

### 11. 什么是会话劫持？目的是什么？

会话劫持是攻击者在能看到受害者与服务器之间流量时，利用观察到的连接信息向 TCP 数据流插入伪造数据包，从一方手中**窃取已建立连接并冒充该方**。典型目标是在受害者完成应用验证后接管会话，以受害者身份访问应用。课件描述攻击者可向受害者发送伪装成服务器的 RST，再利用嗅探获得的序列号向服务器发送数据。对 TCP 载荷进行加密能使攻击者难以注入可用内容。**依据**：chapter 7 new，第 19—22 页。

### 12. 互联网上两种针对 DNS 系统的攻击是什么？

第一类**攻击实际 DNS 服务器**，使服务器掉线；第二类**攻击 DNS 协议及其缺少验证的环节**，用错误答案将客户端引到错误 IP。第二类包括修改服务器内的域名映射、DNS 缓存中毒以及向单个客户端发欺骗应答。缓存中毒影响使用该缓存的请求；针对客户端的欺骗应答影响范围较小。**依据**：chapter 7 new，第 37、40—41 页。

### 13. 网络防火墙从宏观上怎样工作？有哪些种类？

防火墙位于网络流量经过的位置，用**规则引擎**检查数据包或连接，决定允许还是阻止。规则可为**无状态**（逐包独立判断）或**有状态**（结合先前包、连接状态判断）。课件列出的四种网络防火墙是：**透明防火墙**（在物理网络层转发符合规则的流量）、**过滤/屏蔽路由器**（按协议、IP、端口等过滤）、**基于 NAT 的防火墙**（在地址转换基础上加规则限制）、**应用防火墙**（通过应用网关连接并可验证用户）。**依据**：chapter+10，第 3—8 页。

### 14. 交换机和集线器有何安全差别？哪个更安全？为什么？

集线器使同一共享介质上的设备更容易看见彼此流量，且以半双工方式工作；交换机依据地址表把普通单播流量送往目标端口，其他端口的设备一般看不到，并支持全双工。因此，**在减少普通流量嗅探方面，交换机更安全**。但课件也讲到交换机地址表被填满、MAC 冒用和 ARP 中毒等情形可削弱这种隔离，所以不能把交换机看作完整安全保障。**依据**：chapter 5，第 12—16、22—27 页。

### 15. 人工智能时代，如何以新视角分析和理解网络安全？——从大实验 B 任务看

可把网络安全问题从“看到某个危险函数就断定有漏洞”，转为**可核对的证据链与分阶段验证**。本组大实验 B 任务用 LLM 辅助静态审计 SQL 注入、XSS、命令执行的三个固定代码样本，固定输入和测试条件，仅改变 Prompt 的 V1、V2、V3 版本，形成 **3 个主样本 × 3 个版本 = 9 次受控调用**。Prompt 逐步要求模型交代输入如何流向危险操作、引用实际代码与片段行号、说明漏洞成立条件、检查防护及反例、列出未知项。这样，AI 可帮助发现候选风险和组织审计证据，但**模型结论仍是静态判断**，不能直接等同于真实可利用漏洞。B 已完成受控调用、原始结果归档与定性比较；人工复核由 C 承担，动态证据由 D 关联，最终统计由 E 去重整合。现有 3 个主样本不足以证明某版本普遍更准确，也不能把 9 次调用当成 9 个独立漏洞。这体现了智能时代的分析方式：利用 AI 提高审计可追溯性，同时用人工复核和实际证据约束结论。**依据**：《B-交付文档.docx》“结论”“B/C/D/E 交接”；《B任务汇报问答准备.docx》“一句话总述”“问题 1—5、10、13—14”。

### 16. 什么是零日漏洞？

课件将零日漏洞解释为软件或硬件中尚未被厂商知晓、因此还没有相应补丁的安全缺陷；“零日”强调攻击者首次利用时厂商几乎没有预先修复时间。**依据**：chapter+10，第 31 页。

## 二、补充知识速记

### TCP

TCP 是传输层协议，使用端口号区分应用与连接，建立连接时采用三次握手；课件讨论了 SYN、ACK、RST、FIN、序列号和窗口等字段。安全上要记住：SYN 半打开连接可能造成资源耗尽；攻击者若能看到流量，可能伪造 RST 断开连接或劫持会话。**依据**：chapter 3，第 21—23 页；chapter 4，第 11 页；chapter 7 new，第 6—24 页。

### DNS

DNS 把域名转换为 IP 地址，采用层次化名称服务器。课件中的解析有递归和迭代两种模式；DNS 请求通常使用 UDP 的 53 端口，课件还提到回复较大时支持 TCP。安全重点是错误应答、服务器条目篡改、缓存中毒及服务器不可用。**依据**：chapter 3，第 16—18 页；chapter 7 new，第 32—42 页。

### 防火墙：作用、类型、工作方法

**作用**：根据安全规则控制跨网络区域的流量。**工作方法**：规则引擎检查经过的数据包，记录、验证或转发、阻断；无状态规则逐包判断，有状态规则结合连接上下文。**四种类型**：透明防火墙、过滤路由器、NAT 防火墙、应用防火墙。**依据**：chapter+10，第 3—8 页。

### DMZ

DMZ（非军事区）是公网与内网之间的隔离区域，放置 Web、邮件等对外服务。防火墙分别控制外网—DMZ、DMZ—内网的流量，尤其严格限制从 DMZ 进入内网，降低对外服务器被攻陷后的扩散风险。课件介绍单防火墙三接口和双防火墙两种部署。**依据**：chapter 6，第 50 页；chapter+10，第 9—13 页。

### IDS 与 IPS 的区别

IDS 观察流量并按规则记录、告警，指出可能的攻击；IPS 也检测流量，但通常位于流量经过的路径上，能直接阻塞匹配规则的流量。两者都可能误报或漏报；IPS 误报还可能阻断正常业务。**依据**：chapter+10，第 14—16 页。

### 沙箱

沙箱是与真实系统隔离的虚拟分析环境。把可疑文件或程序放入其中运行，观察其行为，辅助识别未知恶意代码，减少对真实系统的影响。课件强调“隔离与观察”，并指出恶意软件可能识别沙箱而隐藏行为。**依据**：chapter+10，第 24—30 页。

### 零日漏洞

指厂商尚未知悉、无相应补丁的缺陷。它之所以难防，是因为传统依赖已知特征或补丁的措施在首次利用时可能无从匹配；课件将沙箱列为分析此类未知威胁的一种手段。**依据**：chapter+10，第 30—31 页。

### 蜜罐

蜜罐是伪装成真实系统、服务或数据的诱饵。它吸引并记录攻击者行为，用于早期预警、研究攻击手法和收集威胁情报；其主要价值是观察与预警，不能代替防火墙等直接防护。**依据**：chapter+10，第 34—38 页。

## 三、易混点

- **ARP 欺骗 / ARP 缓存中毒**：前者是利用虚假 IP—MAC 对应关系的攻击方式；后者强调错误映射进入受害者 ARP 缓存后的状态。依据：chapter 6，第 7—8、16 页。
- **SYN 雪崩 / 会话劫持**：前者耗尽建连资源，影响可用性；后者接管已有会话并冒充通信一方。依据：chapter 7 new，第 13—14、19—22 页。
- **DNS 缓存中毒 / 客户端欺骗应答**：前者污染服务器缓存；后者针对单个客户端请求。依据：chapter 7 new，第 40—41 页。
- **交换机 / 防火墙**：交换机主要按硬件地址转发、减少普通旁路嗅探；防火墙依据安全规则决定流量能否通过。依据：chapter 5，第 13—14 页；chapter+10，第 3 页。
